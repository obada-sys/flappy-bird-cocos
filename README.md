# Flappy Bird — Cocos Creator

A Flappy Bird-inspired 2D game developed using **Cocos Creator 3.8** and **TypeScript**.

This is a collaborative learning project created by two students studying Software Engineering and Data Analysis.

## Project Goals

- Learn 2D game development using Cocos Creator.
- Improve TypeScript programming skills.
- Practice Git and GitHub collaboration.
- Understand game physics, collision detection, and UI development.
- Explore game analytics and player behavior analysis.

## Technologies

- **Game Engine:** Cocos Creator 3.8
- **Programming Language:** TypeScript
- **Version Control:** Git & GitHub
- **Data Analysis:** Python, SQL (planned)
